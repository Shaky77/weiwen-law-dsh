# review 档六步执行规格（定稿 2026-09-02）

> 本文件是「判不出来就 REVIEW，不猜」这条铁律的**可执行规格**。
> 铁律只说"交还人类"，本文件规定交还时**必须带什么、不许少什么**。

## 一、规格原文（作者 2026-09-02 定稿）

> 判不出来，标注后返回用户裁决，但不代表可以放行。**宁可先拦截，搁置 BUG，标注，返回用户裁决，等待用户裁决后再执行，也不可直接放。**
> 只是标注 BUG 后需要**先推演预测一下后果，一同反馈给用户，提供推演预测后果的参考**，而不是什么都不做。

## 二、六步拆解（每步必须有产出）

| # | 步骤 | 产出 | 实现位置 |
|---|---|---|---|
| ① | 不放行 | review ≠ allow | 引擎三态裁决 |
| ② | 先拦截 | 阻断该步、不扩散、不调 `next()` | `src/index.js` pre-execute 闸门 |
| ③ | 搁置 + 标注（留证） | `bugKey`（稳定 BUG 身份，可追溯） | 引擎 `_markIntercept` / 适配层 `bugKeyOf` 补挂 |
| ④ | 推演后果 | `branches:{bS,bD}` 双路终态 | `engine.deduceRisk()` |
| ⑤ | 连推演一起交还人类 | 裁决对象携带 `branches` + 人可读摘要 | **本轮补齐（2026-09-02）** |
| ⑥ | 等人类裁决后再执行 | 阻断即止；裁决回传通道 | 当前：**阻断已实现，回传通道未开** |

## 三、为什么对外语义仍是 `deny`

DSH 宿主契约只识别两种返回：`{kind:'deny', reason}` 拦截，或 `return next()` 放行。
返回 `kind:'review'` 属**宿主未定义类型**，存在被当作未知类型放行的风险。

按「宁可先拦截，不可直接放」，适配层统一：

- **阻断语义用 `deny`**（宿主一定拦得住）
- **待裁决语义用附加字段表达**：`humanDecision:true` + `awaitingHuman:true` + `branches`

即：**用宿主听得懂的话说"拦住"，用附加字段说"这是挂起不是终局"。**

## 四、推演后果的内容

`deduceRisk(call)` 在同一语义信号集 `s` 上并行跑两条分支：

- **S+1 路径**（稳态增量）：放行后的终态
- **D-1 路径**（破窗侵蚀）：越界后的终态，含 `note` 说明侵蚀原因

裁决依据（无等号，少一点或相等都视为不行）：

- `erosion <= -3` → deny（高风险）
- `erosion < 0 || sOk !== true` → **review（中风险，本规格适用）**
- `finalS === +1 && erosion === 0` → allow（双成立）

交还人类时，两条分支**都给**——不替人做选择，但把两条路的终点摆出来。

## 五、副作用分析（为什么适配层补算推演是安全的）

`deduceRisk()` 只做 `inferCallSemantics` + 两次 `simulateBranch`，**不写任何状态**：

- 不调 `recordDeduction`（M 沉淀），不会重复计入历史刻痕
- 不动 `failureStreak`（破窗计数）
- 不动 `sessWritten` / `steadyLedger`

⇒ 适配层对已裁决为 review 的 call **再调一次 deduceRisk 补算推演，是纯读操作**，不污染引擎状态。

（注：引擎内部 `decideToolCall` 走推演档时已在 L1118 调过一次 deduceRisk 并 `recordDeduction`；适配层补算不重复沉淀。）

## 六、实现对照（本轮补齐后）

| 步骤 | 补齐前 | 补齐后 |
|---|---|---|
| ① 不放行 | ✅ | ✅ |
| ② 先拦截 | ✅ | ✅ |

| ⑥ 回传通道 | ❌ review 被呈现成 deny，`humanDecision` 被吞 | ✅ `humanDecision:true` / `awaitingHuman:true` 透传（**通道本身仍待开**） |

## 七、边界声明

- 本规格**不改判据、不扩词表、不动 `src/core/`**。全部补齐动作落在适配层（`src/index.js`）——
  DSH 是导图的降维层，降维层是**钩子载体**，补钩子属其本职。
- 补挂 `bugKey` **不调用 `_markIntercept`**：避免污染 M 档 `mBugForce` 计数（那会改变达封顶升级行为）。
  补挂的 bugKey 仅作**追溯身份**用，不参与闭环闸门。
- ⑥ 裁决回传通道属**新能力**（非修 bug），需宿主侧配合，本轮不开。
